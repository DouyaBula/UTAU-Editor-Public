# Slider Toolbox Symbol Visual Reference

This is the visual reference for Slider Toolbox symbol inputs.

The previews are rendered from `osu.Game.Rulesets.Osu/Edit/Resources/Fonts/NotoSansMath-Regular.ttf`, the same font file used by the current symbol path generator. Each card shows:

- the input token to type in `Symbol` or `Sequence`
- the rendered glyph preview
- the Unicode codepoint used by the current mapping

For sequence generation, enter tokens separated by spaces, for example:

```text
A B C alpha beta gamma
```

Use the matching toolbox group for the token set. For example, choose `Greek lowercase` for `alpha beta gamma`, `Blackboard letters` for `R C Q`, and `Set / logic` for `forall exists subset`.
