# Contributing to UTAU Editor

This is a personal project shared informally. Bug reports and focused improvements are welcome; there is no promised review or release schedule.

Report custom-editor issues in **this repository**, not the official osu! tracker. Include the version/platform, steps to reproduce, expected/actual result and a minimal map or screenshot when useful. Remove private paths, tokens and unpublished content from logs before sharing.

For code changes, preserve native beatmap compatibility and the upstream merge relationship. Reuse the shared tool UI and preview/Undo components; see the [maintainer guide](docs/maintainer-guide.md). Build the desktop project and run tests relevant to the change. Disclose substantial AI assistance and describe what you actually verified.

Changes to upstream projects are governed by their own contribution policies. This document applies only to UTAU Editor.
