# UTAU_Editor v9 Changelog

Release date: 2026-06-19

This version focuses on consolidating slider generation, making editor snapping configurable, and adding an optional stable-export slider path optimizer.

## Slider Toolbox Consolidation

The old standalone Shape slider generator has been removed. Its workflow is now covered by the unified `Slider Toolbox`.

- `Slider Toolbox` can generate a single slider by setting `Frames` to `1`.
- When `Frames = 1`, end-frame controls are disabled and ignored.
- Multi-frame generation still interpolates start/end parameters to create slider sequences.
- The tool no longer uses animation-only naming because it now covers both static slider generation and slider sequence generation.

### UI Entry

- Left sidebar: `Generate > Slider Toolbox`

### Code Entry

- `osu.Game.Rulesets.Osu/Edit/GenerateToolboxGroup.cs`
  - Exposes `Slider Toolbox` as the single parametric slider generation entry.
- `osu.Game.Rulesets.Osu/Edit/ParametricSliderAnimationPopover.cs`
  - Handles both one-frame and multi-frame generation.
  - Disables end-frame inputs when frame count is one.
- `osu.Game.Rulesets.Osu/Edit/ParametricSliderGenerator.cs`
  - Keeps shared shape generation, object transform, and head path type helpers.

## Slider Object Transform Controls

Generated sliders now support object-level translation and rotation in addition to the existing scale controls.

- `Start offset X / Y` and `End offset X / Y` control object translation.
- `Start rotation` and `End rotation` control object rotation.
- The same controls work for one-frame generation and multi-frame interpolation.
- Rotation and translation are applied to the generated slider object, not to the underlying shape formula itself.

### UI Entry

- `Generate > Slider Toolbox > Object`

### Config Entries

- `EditorParametricSliderOffsetX`
- `EditorParametricSliderOffsetY`
- `EditorParametricSliderRotation`
- `EditorParametricSliderAnimationEndOffsetX`
- `EditorParametricSliderAnimationEndOffsetY`
- `EditorParametricSliderAnimationEndRotation`

## Generated Slider Head Path Type

The first control point path type is now configurable.

- Available head path types:
  - `Linear`
  - `Bezier`
  - `Perfect curve`
  - `B-spline`
  - `Catmull`
- `Inherited` is intentionally not exposed as a head path type.

### UI Entry

- `Generate > Slider Toolbox > Head path type`

### Config Entry

- `EditorParametricSliderHeadControlPointType`

## Tick Rate Lower Bound

Beatmap metadata `Tick Rate` now allows `0.5`.

- The lower bound is now `0.5` instead of `1`.
- The setting remains discrete, matching stable-supported values:

```text
0.5, 1, 2, 3, ...
```

### Code Entry

- `osu.Game/Screens/Edit/Setup/DifficultySection.cs`

## Snap Target Configuration

Editor snap targets are now configurable from the top `UTAU_Editor` menu.

- `Nearby object snap targets`
  - Controls snapping to nearby object targets such as circles and slider head/tail points.
- `Slider control point snap targets`
  - Controls snapping to slider control points.
- `Snap target threshold`
  - Controls the slider control point snap radius.
  - Setting this to `0` effectively disables slider control point snap radius matching.

### UI Entry

- Top menu: `UTAU_Editor > Snapping`

### Config Entries

- `EditorNearbyObjectSnapTargets`
- `EditorSliderControlPointSnapTargets`
- `EditorSliderControlPointSnapTargetThreshold`

### Code Entry

- `osu.Game/Screens/Edit/Editor.cs`
  - Adds the `UTAU_Editor > Snapping` menu group.
- `osu.Game.Rulesets.Osu/Edit/OsuHitObjectComposer.cs`
  - Applies the nearby object and slider control point snap target toggles during placement.

## Optional Stable Slider Export Optimization

Added a separate compatibility export path that runs a slider path optimizer before writing legacy `.osu` data.

- The new export option is opt-in.
- The original `For compatibility (.osz)` export path keeps the default lazer behavior.
- The optimizer targets dense sampled slider paths generated by `Slider Toolbox`.
- The main goal is to reduce stable integer-coordinate quantization artifacts.
- Velocity-transformed slider handling is included but remains experimental and may require future tuning.

### UI Entry

- `File > Export > For compatibility with slider optimization (.osz)`

### Code Entry

- `osu.Game/Screens/Edit/Editor.cs`
  - Adds the optimized export menu item.
- `osu.Game/Beatmaps/BeatmapManager.cs`
  - Adds `ExportLegacyWithSliderOptimization(...)`.
- `osu.Game/Database/LegacyBeatmapExporter.cs`
  - Accepts an optimizer flag and calls the optimizer only for the new export path.
- `osu.Game/Database/StableSliderPathOptimizer.cs`
  - Contains the stable slider path optimization logic.
- `osu.Game/Localisation/EditorStrings.cs`
  - Adds the optimized export menu string.
