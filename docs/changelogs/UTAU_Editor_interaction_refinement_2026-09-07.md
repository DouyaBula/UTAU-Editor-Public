# UTAU Editor — 交互与性能修整（2026-09-07）

## Slider 曲线交互

- 修复 Pen 连续拖拽期间 SV 倍率已经变化、实际 Velocity 却尚未刷新的问题。拖拽中轻量刷新速度与 tick 间距计算，提交时仍完整重建 defaults；实时 Duration 不再使用旧速度。
- 不记录会话快照的拖拽帧不再额外复制并归一化整条锚点路径。
- 会话历史改为反向索引遍历；锚点命中检测及手柄绘制移除逐节点临时数组。
- 修正 Curvature pen 的自动平滑说明，以及对齐/分布快捷键的 Y 键标注。
- 曲线运算类型变化时清除旧预览，避免提交上一次运算的结果；预览缩放按实际面板空间计算。
- 保持原生 slider 存储格式，不引入额外导出格式，不修改默认兼容导出算法。

## Pattern Gallery

- 修正预览重复内边距；边界计算改为单次遍历，避免收集整份路径点副本。
- 密集预览跳过的 slider 不再生成头尾装饰；限制路径采样数量及重复端点标记，避免高 repeat 数导致大量重叠 drawable。
- 卡片名称与操作按钮分行；筛选、排序时回到第一页并合并重建请求。
- 面板销毁时解除选择事件订阅。
- 库保存使用安全文件替换；批量导入按 ID 索引匹配，避免逐条线性查找。

## 侧栏排序

- 修复加载阶段尚未 alive/present 的组被 FlowingChildren 排除，导致恢复顺序无效的问题。恢复改为读取全部已挂载子项并按 layout position 排序。
- 移除重复延迟恢复、直接配置写入和同步刷盘补丁，沿用配置绑定的正常持久化流程。
