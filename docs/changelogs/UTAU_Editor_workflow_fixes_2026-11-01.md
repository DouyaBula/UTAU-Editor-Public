# UTAU Editor — 全局 offset、工具面板与 SV 继承修复

日期：2026-11-01。状态：2026-11-02 用户实机验收通过，确认提交并推送。

## 全局 offset

- 入口：切换到 Timing 页面，右侧设置区域顶部的 `Global offset...`。
- 输入有符号的整数毫秒数：正数整体后移，负数整体前移。例如替换后的音频开头多了 250 ms 空白，输入 `+250`。
- 点击 `Apply to entire difficulty` 一次移动当前难度的全部 timing/effect points、物件、kiai、休息段、书签与已设置的预览点。
- 保留各段 BPM、拍号、相对拍位、slider 路径、SV、repeat 与 duration；不额外 snap。
- 不修改音频文件、其它 difficulty、video 或 storyboard。音频替换仍使用原有入口。
- 应用前检查时间范围；若物件或时间标记将越过 0 ms，整次操作不执行。Timing points 本身允许负 offset。
- 整次操作使用一个编辑事务，支持一次撤销/重做。补齐撤销器的预览点恢复，并调整休息段恢复顺序，避免被自动生成的休息段覆盖。

## 工具面板

- 17 个编辑工具弹窗统一接入 `EditorPopover`：根据实际弹窗宿主尺寸限制宽高，长内容可滚动，滚动条单独占位，不盖住操作控件。
- 覆盖 Hitsound、Slider Toolbox 1/2/3、Pattern Gallery、Slider curves、难度显示、精确移动/缩放/旋转、SV 工具、Convert to stream 等。
- Hitsound 缩小默认高度和内边距；Slider Toolbox 1 的固定像素左右栏改为比例布局；Toolbox 1/2 的若干参数行支持窄窗口换行；Gallery 导入/导出按钮使用相对宽度。
- 滚到面板底部后，如果内容分组继续展开或窗口尺寸变化，滚动位置跟随底部，保持最后一行可访问。
- 工具内部提供独立的子弹窗宿主。打开文件选择器不再替换外层工具，初始化、清空或拖入文件也不会错误关闭外层面板；文件选择器自身按可用空间调整尺寸。

## 自适应 SV 与放置继承

- 原先借助缓存是否有效来猜测 SV 数值变化是否由用户操作产生。自动保持时长、对象重处理等引起的数值同步可能被误判为手动覆盖，导致默认 SV 停止继承。
- 改为显式区分用户编辑和来源同步；仅真正的手动调整或 preset 操作进入手动覆盖状态。
- 移除内部 SV 值的两位小数量化，显示格式仍保持简洁，不再把精确自适应 SV 截断后传给新物件。
- classic 与 pen 放置均按实际放置时间直接读取来源 slider 的精确 SV，不依赖上一帧面板缓存。位于首个 slider 之前时，无手动覆盖则回到 1x。
- 保留用户主动指定默认 SV 和编辑所选 slider SV 的原有工作流。
